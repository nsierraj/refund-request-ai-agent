# Returns

## Return window
You can return most items within 30 days of the delivery date. The 30 days start the day the carrier marks the package delivered, not the day you ordered.

## What can't be returned
Items marked "Final Sale" at checkout can't be returned or refunded. Opened bedding and bath textiles can be returned only if they arrived damaged or defective. Gift cards are never refundable.

## Orders that haven't arrived
An order that is still processing or in transit can't be refunded yet. If it hasn't shipped, the customer can ask to cancel it instead. If it has shipped, wait for delivery and then start a return.

## Exchanges
We don't do direct exchanges. Return the item for a refund and place a new order for the one you want.
